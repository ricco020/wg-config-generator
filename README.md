# wg-config-generator

> CLI generator for WireGuard server + multi-client configurations, with QR code output, IPv4/IPv6 dual-stack support, and integrated firewall snippet generation.

Companion editorial site: **[VPNSmith](https://www.vpnsmith.com/)** — VPS self-host VPN benchmarks.

## What it does

Generates production-ready WireGuard configurations for self-hosted VPN servers running on commodity VPS (Contabo, Hetzner, OVH, DigitalOcean, Vultr).

- Server config (`/etc/wireguard/wg0.conf`)
- N client configs with isolated `/32` allowed-IPs
- ANSI QR codes for mobile clients
- Firewall snippets (UFW, iptables, nftables)
- DNS leak-prevention recommendations
- Optional split-tunnel routing rules

## Quickstart

```bash
git clone https://github.com/ricco020/wg-config-generator
cd wg-config-generator
chmod +x wg-gen

./wg-gen init --server-name forge1 --endpoint 1.2.3.4:51820 --net 10.66.66.0/24
./wg-gen add-client --name alice
./wg-gen add-client --name bob --routes 10.66.66.0/24  # split tunnel
./wg-gen list
./wg-gen export-firewall ufw      # prints UFW snippet
./wg-gen qr alice                  # ANSI QR code to terminal
```

## Architecture

```
configs/
├── server/wg0.conf       # generated server config
├── clients/
│   ├── alice.conf        # per-client config
│   ├── alice.qr.txt      # ANSI QR code
│   ├── bob.conf
│   └── bob.qr.txt
└── keys/
    ├── server.{key,pub}
    ├── alice.{key,pub,psk}
    └── bob.{key,pub,psk}
```

Keys are generated with `wg genkey` / `wg genpsk` (CryptoBox-compatible). Pre-shared keys per peer are generated by default (defense in depth against quantum adversary).

```
apt install wireguard qrencode iptables-persistent
```

Bash 4+. Python 3.8+ for the `wg-gen` CLI.

## Security guardrails

- Refuses to generate configs with the same key twice
- Sets `umask 077` before writing key files
- Verifies endpoint is a public IP (not RFC 1918) when adding clients
- Warns if `PostUp`/`PostDown` rules differ from the documented hardening template
